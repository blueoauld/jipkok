# 제약 조건

집콕 전체의 형식 규칙, 한도, 보존 기간, 스케줄, 시스템 상한을 모은 문서다. 원본은 코드의 상수이며, 값이 바뀌면 이 문서도 함께 고친다. (기준: 2026-09-09)

## 계정

| 항목 | 값 | 위치 |
| --- | --- | --- |
| 휴대폰 번호 | E164 형식만. 한국 `+8210`, 일본 `+81[789]0`, 대만 `+8869` 뒤 8자리 | `Member.PHONE_NUMBER_PATTERN` |
| 번호 저장 길이 | 16자 | `Member.PHONE_NUMBER_LENGTH` |
| 비밀번호 | 8~30자 | `SignupRequest` |
| 나이 | 19세 이상 90세 이하만 가입 | `MemberService.MIN_AGE/MAX_AGE` |
| 닉네임 | 10자, 한글(자모 포함), 가나, 한자, 영숫자, 공백만 | `Member.NICKNAME_MAX_LENGTH/PATTERN` |
| 코멘트 | 100자 | `Member.COMMENT_MAX_LENGTH` |
| 자기소개 | 1,000자 | `Member.BIO_MAX_LENGTH` |
| 회원 언어 | KO, JA, EN, ZH_TW (기본 KO) | `MemberLocale` |
| 닉네임 검색 | 2자 이상 (앞뒤 공백 제거 후) | `global/repository MIN_KEYWORD_LENGTH` |
| 앱 잠금 재잠금 | 앱 시작 시, 그리고 백그라운드 30초 이상 뒤 복귀 시 (inactive는 세지 않음) | `app lib/lock RELOCK_AFTER_MILLIS` |

## 보존 기간과 정리 스케줄

전부 한국 시간 기준이고, 삭제는 DB 커밋 후 R2 파일을 지운다.

| 시각 | 작업 | 보존 기간 |
| --- | --- | --- |
| 04:00 | 고아 업로드 정리 | 1일 |
| 04:30 | 나간 채팅방 (대화, 사진 포함) | 90일 |
| 04:35 | 삭제된 피드 | 90일 |
| 04:40 | 탈퇴 회원 (사진, 닉네임 이력 포함) | 90일 |
| 04:45 | 삭제된 고민 글과 댓글, 처리된 신고 (미처리는 보존) | 90일 |
| 04:50 | 접속 로그, 만료된 정지 기록 | 90일 / 365일 |
| 04:55 | 인증번호 기록, 보상 이력(출석, 접속, 광고) | 90일 |
| 9~21시 3시간 간격 | 피드 알림 발송 | - |

스케줄러에는 분산 락이 없다. 단일 인스턴스 전제이며, 스케일아웃 시 ShedLock을 붙이기로 했다.
